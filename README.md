# 海克斯大乱斗 · 英雄对决

原创的俯视角单路 5V5 英雄竞技原型。操控近战剑士「苍锋」，与四名电脑队友并肩对抗五名敌方电脑英雄，摧毁敌方水晶获胜。无框架、无第三方运行时依赖，所有角色和场景由 Canvas 绘制。

## 5V5 阵容

| 定位 | 蓝方 | 红方 | 电脑技能与行为 |
| --- | --- | --- | --- |
| 战士 | 苍锋（玩家） | 赤刃 | 近战普攻、延迟范围打击 |
| 坦克 | 磐石 | 铁壁 | 护盾、近身范围伤害与减速 |
| 射手 | 逐风 | 夜翎 | 远程普攻、多目标箭矢、近身后拉开距离 |
| 法师 | 霜语 | 烬火 | 远程普攻、带预警的范围法术 |
| 辅助 | 晨星 | 暮光 | 优先治疗附近受伤队友并给予护盾 |

九名 AI 使用同一套按阵营计算的推进、选敌、塔下避险和低血撤退规则；阵亡后回到各自泉水复活，随对局时间升级。阵容面板显示十名英雄的血量、等级、KDA 和复活倒计时，点击头像可查看位置，空格回到自己的英雄。

## 本地启动

运行 `npm start`，打开 http://localhost:5173。也可直接打开 `index.html`。

## 操作

| 操作 | 效果 |
| --- | --- |
| 右键地面 | 点击移动 |
| 右键敌人 | 锁定普攻，超出距离自动追击 |
| 左键单位 | 查看目标生命 |
| Q | 向鼠标方向释放扇形剑斩 |
| W | 开启护盾 |
| E | 向鼠标位置突进，伤害沿途敌人 |
| R | 向指定区域施放延迟落地的大招 |
| S | 停止移动和攻击 |
| 空格 | 镜头重新跟随英雄 |
| 小地图左键 | 查看指定区域 |
| B | 装备商店，需在己方泉水购买 |
| P | 暂停 / 继续 |

手机：点击地面移动、点击敌人追击；点击技能按钮后，再点击地图施放。W 立即释放。

## 对战规则

- 双方每 18 秒派出一波小兵，防御塔优先攻击小兵。
- 在敌塔范围内伤害敌方英雄会吸引塔的仇恨。
- 敌方单位在附近阵亡时获取经验；亲手击杀获取金币和补刀。
- 升级三选一海克斯强化，九种强化均可叠加。
- 泉水恢复生命与法力，可购买三种装备，每种限购三次。
- 英雄阵亡后复活。先摧毁防御塔才能伤害水晶。
- 双方比分统计整队英雄击杀；个人助攻只计算最近 10 秒内实际伤害过该敌人的英雄。
- 当前为一名真人加九名电脑的 5V5，尚未实现多人联网和玩家英雄选择。

## GitHub Pages

仓库 Settings → Pages → Source 选择 **GitHub Actions**。首次启用后，在 Actions 里运行 **Deploy game to GitHub Pages**；之后推送到 `main` 自动发布。
