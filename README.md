# 海克斯大乱斗 · 英雄对决

原创的俯视角 3D 单路 5V5 英雄竞技原型。操控近战剑士「苍锋」，与四名电脑队友并肩对抗五名敌方电脑英雄，摧毁敌方水晶获胜。

## 4.0 引擎与画面

- 新版全屏战场、悬浮计分板、可展开阵容与强化面板，以及适配手机的底部游戏 HUD。
- 使用 Babylon.js / WebGL 2，原创程序化建模；模型拥有真实体积、材质与光照。
- 五种职业有独立的铠甲、披风、头饰与武器：发光剑刃、盾牌、长弓、法杖及治疗者光环。
- 英雄具有行走、转向、挥击和护盾动画；阵容头像直接由同一套 3D 模型离屏渲染。
- 长桥包含石砖凹凸材质、积雪城垛、桥墩、冰柱、雪松与峡谷；水晶、防御塔、技能和弹道有发光效果。
- 使用正交俯视镜头、环境反射、实时柔和阴影及飘雪。滚轮或地图左下角的加减按钮可缩放。
- 点击与技能落点通过相机射线计算，屏幕坐标和战斗坐标相互独立。

## 5V5 阵容

| 定位 | 蓝方 | 红方 | 电脑技能与行为 |
| --- | --- | --- | --- |
| 战士 | 苍锋（玩家） | 赤刃 | 近战普攻、延迟范围打击 |
| 坦克 | 磐石 | 铁壁 | 护盾、近身范围伤害与减速 |
| 射手 | 逐风 | 夜翎 | 远程普攻、多目标箭矢、近身后拉开距离 |
| 法师 | 霜语 | 烬火 | 远程普攻、带预警的范围法术 |
| 辅助 | 晨星 | 暮光 | 优先治疗附近受伤队友并给予护盾 |

九名 AI 使用同一套按阵营计算的推进、选敌、塔下避险和低血撤退规则；阵亡后回到各自泉水复活，通过被动经验和附近击杀经验升级。阵容面板显示十名英雄的血量、等级、KDA 和复活倒计时，点击头像可查看位置，空格回到自己的英雄。

## 本地启动

运行 `npm start`，打开 http://localhost:5173。请通过 HTTP 服务访问；ES 模块不能通过双击 `file://` 页面加载。需要支持 WebGL 2 的现代浏览器。

Babylon.js 8.38.0 已随仓库放在 `vendor/`，运行游戏不依赖外部 CDN，也无需在线下载模型。引擎使用 Apache-2.0 许可，见 `vendor/BABYLON-LICENSE.md`。维护依赖时运行 `npm ci` 后执行 `npm run vendor` 可重新生成引擎文件。

## 操作

| 操作 | 效果 |
| --- | --- |
| 右键地面 | 点击移动 |
| 右键敌人 | 锁定普攻，超出距离自动追击 |
| 左键单位 | 查看目标生命 |
| Q | 向鼠标方向释放扇形剑斩 |
| W | 开启护盾 |
| E | 向鼠标位置突进，伤害沿途敌人 |
| R | 向指定区域施放延迟落地的大招 |

手机：点击地面移动、点击敌人追击；点击技能按钮后，再点击地图施放。W 立即释放。

## 对战规则

- 双方每 18 秒派出一波小兵，防御塔优先攻击小兵。
- 在敌塔范围内伤害敌方英雄会吸引塔的仇恨。
- 敌方单位在附近阵亡时获取经验；亲手击杀获取金币和补刀。
- 英雄 3 级开局，最高 18 级；经验门槛采用 LOL 的递增曲线，3→4 需要 480 经验，此后每级增加 100，17→18 需要 1880。
- 每秒获得 12 被动经验；附近敌方单位阵亡提供共享经验，九名 AI 使用相同机制。经验来源和战斗数值针对本原型调整。
- 海克斯仅在开局（3 级）、7、11、15 级触发，每轮三选一，每局最多四个，每个强化本局仅能选择一次。普通升级不会弹出海克斯面板。
- 普通升级增加基础属性并给予一个技能点；Q/W/E 各最多 5 级，大招 R 在 6/11/16 级可升至 1/2/3 级。点击技能上方 ＋ 或按 Shift+技能键加点。
- 阵亡保留等级、技能与强化；阵亡期间解锁的强化会在复活后显示，已选轮次不重复。
- 泉水恢复生命与法力，可购买三种装备，每种限购三次。
- 英雄阵亡后复活。先摧毁防御塔才能伤害水晶。
- 双方比分统计整队英雄击杀；个人助攻只计算最近 10 秒内实际伤害过该敌人的英雄。
- 当前为一名真人加九名电脑的 5V5，尚未实现多人联网和玩家英雄选择。

## 检查

`npm run check` 检查游戏、渲染器和启动脚本语法。
`npm run test:browser` 使用本地 Chromium 的 DevTools 端口验证 5V5、技能、计分和复活，并验证 WebGL 网格、3D 点击、相机缩放、触屏施法与三分钟对局模拟。运行方法见 `tests/browser-smoke.mjs` 顶部。无 GPU 的环境可使用 Chromium 的 SwiftShader 软件渲染。

## GitHub Pages

仓库 Settings → Pages → Source 选择 **GitHub Actions**。首次启用后，在 Actions 里运行 **Deploy game to GitHub Pages**；之后推送到 `main` 自动发布。工作流会一并上传游戏脚本、3D 渲染器和 `vendor/` 引擎文件，支持 `/hks/` 子路径。

部署成功后地址：https://guo-jing.github.io/hks/
